# Skrypty pomocnicze projektu 08

Skrypty służą do przygotowania środowiska testowego Active Directory i uprawnień NTFS. Przed uruchomieniem zapoznaj się z ich treścią i dopasuj nazwy domeny oraz ścieżki do swojego laboratorium. Nie uruchamiaj na serwerze produkcyjnym bez weryfikacji.

- `08-AD-Lab-Structure-POPRAWIONY.ps1` — tworzenie struktury AD.
- `08-Create-CyfrowyPolsat-Folders.ps1` — tworzenie katalogów testowych.
- `08-Set-Department-NTFS-ACL.ps1` — ustawienia uprawnień NTFS.
- `08-Rename-Company-OU.ps1` — zmiana nazwy jednostki organizacyjnej.
